# SnoreSync — The Worst App Idea Ever Pitched

Entry for the make.fun bounty
[u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23).

`main.py` is a deterministic, stdlib-only program. It writes one sentence
(185 characters) pitching the worst, most useless app imaginable to
`/output/entry.txt`:

> SnoreSync records your snoring, uploads it to the cloud, and plays it back
> to your neighbours so they can rate your sleep like a talent show — $4.99
> a month, no mute button, no refunds.

Run it with:

```sh
python3 main.py
```
